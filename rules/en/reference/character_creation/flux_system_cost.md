Flux represents the arcanotechnological energy available for casting spells. It is a major power factor for spellcasters.

| Component        | Cost        | Description                                           |
| ---------------- | ----------- | ----------------------------------------------------- |
| **Reserve**      | 1 pt/point  | Total available Flux pool                             |
| **Per Turn**     | 3 pts/point | Automatic regeneration each turn (very valuable!)     |
| **Recovery**     | 2 pts/point | Flux recovered during a short rest                    |

### Cost Rationale

-   The **reserve** determines how many spells can be cast before exhaustion
-   **Per-turn regeneration** is the most expensive because it enables continuous spellcasting
-   **Recovery** offers flexibility between combats

### Flux Profile Examples

**Major spellcaster** (Arcanotechnician):

-   Reserve: 30 -- **30 points**
-   Per Turn: 8 -- **24 points**
-   Recovery: 3 -- **6 points**
-   **Total Flux: 60 points**

**Fighter with minor spells** (Weapon Master):

-   Reserve: 8 -- **8 points**
-   Per Turn: 3 -- **9 points**
-   Recovery: 1 -- **2 points**
-   **Total Flux: 19 points**
