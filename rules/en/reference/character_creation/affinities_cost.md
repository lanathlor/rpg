Affinities determine which weapons and spells a character can use effectively.

### Combat Affinities

| Type              | Cost per Level |
| ----------------- | -------------- |
| Melee (A.Melee)   | 4 pts          |
| Ranged (A.Ranged) | 4 pts          |
| Special Weapons   | 4 pts          |

Shotgun, sniper, one-handed weapon

### Arcanotechnology Schools

Schools are organized by rarity and power:

| Tier          | Schools                                                                      | Cost/Level |
| ------------- | ---------------------------------------------------------------------------- | ---------- |
| **Pure**      | Pure                                                                         | 8 pts      |
| **Quantum**   | Quantum                                                                      | 7 pts      |
| **Complex**   | Chronodynamic, Gravitonic                                                    | 6 pts      |
| **Advanced**  | Bioarcanotechnology, Magnetic                                                | 5 pts      |
| **Standard**  | Fire, Electricity, Frost, Light, Martial, Ballistic, Illusion, Shadow        | 3 pts      |

### Spell Types

All types cost **5 points per level**:

-   Destruction
-   Alteration
-   Enhancement
-   Weapon
-   Displacement
-   Protection
-   Affliction
-   Summoning
-   Divination

### Affinity Example

A mage specializing in ice:

-   Ranged: 2 -- **8 points**
-   Frost School: 5 -- **15 points** (5 x 3)
-   Destruction Type: 4 -- **20 points** (4 x 5)
-   Alteration Type: 2 -- **10 points** (2 x 5)

**Total affinities: 53 points**
